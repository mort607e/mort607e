## Main project — *RiverSeg* (working title)

> **Status:** Private for now while I prepare a clean open‑source release (docs, tests, sample data). The release plan and scope are outlined below.

**Goal.** End‑to‑end pipeline for estimating **river surface‑water extent** from Sentinel‑1/2 + DEM, converting masks to **centerlines/graphs**, and reporting **topology‑aware metrics** over time.

**Core capabilities**

* Segmentation models (U‑Net, Dynamic U‑Net) with **BCE/Dice/clDice** losses
* Skeletonization & graph building, branch IDs, connectivity checks
* Evaluation: IoU/Dice + topology metrics (connectivity ratio, length coverage, etc.)
* Data pipeline with constrained acquisition, patch filtering, synthetic clouds

**Interested?** → Watch this space and ⭐ the repo once it goes public. If you want early discussion/collab, reach out by email or LinkedIn.
